# Memory Management Simulator

Interactive web-based simulator demonstrating **Segmentation**, **Paging**, **Segmentation with Paging**, and **Comparative Performance Analysis**.

## Folder Structure
- `index.html` — Main UI structure and dashboard layout
- `style.css` — Dark slate-navy & cyan theme styling + block pop-in animations
- `script.js` — Simulation engine with sequential S1..Sn re-indexing, RAM bounds checking, and 1.2s step-by-step allocation animations

## How to Open & Run in VS Code
1. Extract `os-memory-simulator-v4.zip`.
2. Open VS Code -> **File > Open Folder** -> select `os-memory-simulator`.
3. Right-click `index.html` and select **Open with Live Server**.
